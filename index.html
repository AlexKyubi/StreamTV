Инструкция по настройке

Общая подготовка

  • StreamTV – решение для показа рекламы на телевизорах по Wi-Fi. Программа сама включает телевизоры, запускает на них показ, следит за ним и восстанавливает при сбоях. Все экраны показывают ролики синхронно, а ролики хранятся в памяти телевизоров — сеть нагружается только при первом круге.
  • Для трансляции нужен роутер: Archer C80 (до 60 телевизоров) или Archer AX73 (свыше 60 телевизоров) и компьютер с программой StreamTV.
  • Если роутер расположен далеко от телевизоров, поставьте репитер — это повысит скорость и стабильность показа. По возможности подключайте ТВ к сети 5 ГГц.
  • Если Windows Defender блокирует установку или работу программы, добавьте папку StreamTV в исключения и разрешите программе доступ к сети при первом запуске.
  • Скачайте программу по ссылке: StreamTV. Запустите установочный файл и выберите удобную папку. Для работы нужно минимум 2 ГБ свободного места.
  • Для трансляции на смартфоны нужен отдельный компьютер с программой StreamTV. Не объединяйте трансляции для телевизоров и смартфонов в одной сети.
  • Пульт с телефона. Подключите телефон к Wi-Fi магазина, откройте инструкцию этот сайт и нажмите кнопку меню слева вверху (или проведите пальцем от левого края экрана). Пульт сам найдёт компьютер с программой — если браузер спросит доступ к устройствам в локальной сети, нажмите «Разрешить». В пульте: состояние всех ТВ, синхронизация, перезапуск показа, включение ТВ и действия с каждым телевизором (нажмите на ТВ в списке).
    Пульт работает, пока в программе запущена трансляция. Если появится «Нет соединения с сервером» — проверьте, что трансляция запущена и телефон в Wi-Fi магазина, и нажмите «Найти сервер ещё раз».
  • Запускайте трансляцию только после завершения загрузки или обработки видео.
  • Неподходящий роутер или неверная настройка сети приводят к перебоям в показе.
  • При загрузке роликов с сервера проверьте логин и пароль — с неверными данными ролики не загрузятся.
  • Следите за сообщениями программы и столбцом «Внимание» в окне «Телевизоры» — они подскажут, что нужно сделать.

Настройка роутера

  • Подключите роутер Archer C80 (или AX73) к корпоративному роутеру Sulpak через Ethernet-кабель. Управляющий компьютер подключите к Archer C80/AX73 LAN-кабелем (см. схему).
  • Первичная настройка Archer C80/AX73:
    Включите роутер и откройте в браузере tplinkwifi.net или 192.168.1.1. Придумайте логин и пароль для доступа к роутеру.
  • Перейдите: Расширенная ➔ Сеть ➔ DHCP-сервер.
    Установите пул адресов IP: 192.168.1.2 — 192.168.1.249. Резервировать адрес для компьютера не нужно: программа и пульт сами находят друг друга.
  • Отключите Smart Connect: Меню ➔ Беспроводной режим ➔ Настройка ➔ Smart Connect: выкл.
    Для 5 ГГц и 2,4 ГГц укажите имя и пароль сети (например: DemoTV / 11111111) ➔ сохранить. При необходимости перезагрузите роутер.

Настройка WebOS (LG)

  • Откройте настройки ТВ, раздел «Сеть», и подключитесь к Wi-Fi DemoTV.
  • Настройки → Поддержка → Обновление ПО: обновите прошивку ТВ.
  • Отключите автоотключение ТВ (раздел «Общие» → «Система» / «Таймеры» или «Поддержка»).
  • Обязательно разрешите управление по сети — без этого программа не сможет включать ТВ и запускать показ:
    Настройки → Поддержка → Управление по IP → включите управление по сети.
    Настройки → Общие → Устройства → Внешние устройства → включите «Включение ТВ с мобильного устройства» (на старых версиях WebOS: Настройки → Общие → Mobile TV On).
  • В программе нажмите Телевизоры → Найти телевизоры, выделите ТВ и нажмите Добавить выбранные.
  • На экране ТВ появится запрос «Разрешить трансляцию» (Cast) или «Разрешить подключение» — нажмите «Да» пультом ТВ. Больше ничего делать не нужно: показ запускается автоматически при каждом запуске трансляции.

Настройка Tizen (Samsung)

  • Меню → Общие → Сеть: подключитесь к Wi-Fi DemoTV. ТВ нужен доступ в интернет.
  • Меню → Общие → Экономия энергии (Экодизайн) → «Автовыключение»: Выкл.
  • Меню → Общие → Сеть → Экспертные настройки → включите «Включение с мобильного устройства» — так программа сможет включать ТВ по сети.
  • В программе нажмите Телевизоры → Найти телевизоры, выделите ТВ и нажмите Добавить выбранные.
  • На экране ТВ появится запрос на подключение StreamTV — нажмите «Разрешить». Затем появится запрос на трансляцию (Cast) — тоже «Разрешить». Аккаунт Samsung и настройки браузера не нужны: показ запускается автоматически.

Настройка Android TV

  • Включите ТВ, дождитесь загрузки и пропустите первичную настройку Android TV.
  • Настройки → Сеть: подключитесь к Wi-Fi DemoTV.
  • В настройках сети DemoTV отключите случайный MAC-адрес: Конфиденциальность (MAC-адрес) → «Использовать MAC-адрес устройства». Иначе программа может не узнать ТВ после перезагрузки и не сможет включить его по сети.
  • Настройки → Система (Энергосбережение) → отключите автовыключение и переход в режим ожидания.
  • Настройки ➔ Об устройстве ➔ нажмите 7 раз на «Номер сборки», пока не появится режим разработчика.
    Настройки ➔ Для разработчиков ➔ включите Отладку по USB и Отладку по сети (Wi-Fi ADB), если есть.
  • ARG (модели 7500 и старше): на пульте нажмите Menu ➔ 1 ➔ 1 ➔ 4 ➔ 7 ➔ в меню разработчика выберите Debug ➔ ADB enabled: ON. Младшим моделям ARG настройка не нужна.
  • В программе нажмите Телевизоры → Найти телевизоры, выделите ТВ и нажмите Добавить выбранные. Браузер программа установит сама.
  • На экране ТВ появится запрос «Разрешить отладку» — отметьте «Всегда разрешать с этого компьютера» и нажмите OK. Если отладку включить нельзя, ТВ будет показывать через Cast или DLNA — это происходит автоматически.

Обновление видео

  • Если трансляция идёт — нажмите Остановить трансляцию.
  • Нажмите Загрузить рекламный набор и введите логин и пароль учётной записи директора магазина (если вы входили ранее, они подставятся сами). Выберите папку на сервере.
    Готовый поток загрузится сразу — в окне программы появится «Поток загружен. Можно запускать трансляцию».
    Обычные видео после загрузки обработайте кнопкой Обработать видео: задайте качество и запустите обработку. По завершении появится «Видео готово к трансляции».
  • Нажмите Запустить трансляцию. Телевизоры включатся и запустят показ сами, новые ролики заменят старые автоматически.
  • Нажмите Перезапустить показ на ТВ. Если отдельный ТВ всё равно показывает старые ролики — Телевизоры → правая кнопка по ТВ → «Очистить кэш роликов на ТВ».

Запуск в начале дня

  • Компьютер и телевизоры подключены к сети DemoTV.
  • Откройте StreamTV на компьютере и нажмите Запустить трансляцию.
  • Телевизоры с включением по сети включатся сами; остальные включите пультом ТВ — показ на них начнётся автоматически.
  • Откройте пульт с телефона (меню слева на этой странице) и проверьте строку «Играют N из N». Сколько ТВ играет, видно и в заголовке программы. При необходимости нажмите «Синхронизировать».
  • Если ТВ только что установлен, на его экране появится запрос на разрешение подключения — нажмите «Разрешить» пультом ТВ.
